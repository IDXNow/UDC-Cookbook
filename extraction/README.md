# Extraction Recipes

**Data trapped in PDFs and web pages? Not anymore.** Unstructured -> Structured - the AI reads it so you don't have to.

These recipes take raw, unstructured or semi-structured content and produce clean, standardized structured output. The AI interprets, extracts, and organizes the data into a defined schema - no manual data entry required.

Treat these as starter extraction patterns. Update schema design, extraction rules, and prompt guidance to fit your document types, data quality standards, and business workflows.
